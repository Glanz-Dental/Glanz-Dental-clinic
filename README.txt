UPLOAD TO GITHUB PAGES
1. Open this folder after extracting the ZIP.
2. Upload index.html and the complete assets folder directly to the repository root.
3. Do not upload the outer GLANZ_COMPLETE_WEBSITE folder as an extra nested folder.
4. GitHub Pages should use the main branch and /root.
5. Wait for the new deployment then hard refresh the live website.
